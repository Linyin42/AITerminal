AITerminal —— AI 智能终端（网络设备运维助手）
============================================================

【这是什么】
一个用自然语言操作网络设备的桌面软件：左侧是设备库，中间是 AI 助手
（像聊天一样告诉它要做什么），右侧是设备终端（实际下发命令的地方）。
支持 SSH / Telnet / 串口连接，AI 可联网查命令、读本地资料库。

【怎么用】
1. 直接双击 AITerminal.exe 即可运行，无需安装任何东西。
2. 首次使用，在右侧「AI 助手 → AI 高级」里填入你的 API Key
   （默认使用 DeepSeek，也可切到 Anthropic / OpenAI 兼容接口），
   保存后 AI 功能即生效。
3. 左侧「设备库」点「新建连接」添加设备（SSH/Telnet/串口），
   保存后双击设备即可连接（密码不会落盘保存）。
4. 连上设备后，切到中间「Catty 对话」，用大白话下达任务，例如：
   “检查所有接口状态，找出 down 的端口并告诉我原因”
   AI 会先用文字说明，再把要执行的命令以卡片列出，
   点「执行」即下发到右侧终端（涉及配置变更的命令会先弹确认框）。
5. 右侧终端实时显示设备输出，可直接敲命令，也能用工具栏做
   批量下发 / 配置比对 / 多设备巡检 / 保存日志。

【界面布局】
   左：设备库（Vault）   中：AI 助手（窄）   右：终端（最大）

【安全机制】
· 危险命令（reboot / delete / undo all / factory-reset 等）代码级拦截。
· 任何配置类命令下发前，都会先把完整命令清单展示给你确认，
  确认后才执行；默认不自动保存到设备（save 需手动）。
· 设备密码不写入任何文件。

【数据存放】
所有配置、日志、资料库默认在用户目录：
   Windows: C:\Users\<你>\.aiterminal\
重新分发时只发 AITerminal.exe 即可，每个使用者有各自独立的配置。

【重新打包（开发者）】
   安装依赖：pip install pyinstaller pillow
   执行：build.bat    （生成 dist\AITerminal.exe）
