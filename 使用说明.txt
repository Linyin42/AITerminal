AITerminal —— AI 智能终端（网络设备运维助手）v0.7
============================================================

【这是什么】
一个用自然语言操作网络设备的桌面软件：左侧是设备库（设备卡片网格，
按厂商/协议显示不同颜色的圆形图标），中间是 AI 助手（像聊天一样告诉
它要做什么），右侧是设备终端（实际下发命令的地方）。支持 SSH / Telnet /
串口连接，AI 可联网查命令、读本地资料库。

【怎么用】
1. 直接双击 AITerminal.exe 即可运行，无需安装任何东西。
2. 首次使用，在中间「AI 助手 → AI 高级」里填入你的 API Key
   （默认使用 DeepSeek，也可切到 Anthropic / OpenAI 兼容接口），
   保存后 AI 功能即生效。
3. 左侧「设备库」点顶部的「+ 新建」按钮添加设备（SSH/Telnet/串口）。
   也可用顶部搜索框按主机/IP/用户名/厂商过滤现有设备。
4. 设备操作：
   · 双击设备卡片    → 连接
   · 右键设备卡片    → 弹出菜单（连接 / 编辑 / 删除）
   · 选中后顶部按钮  → 编辑 / 删除
5. 连上设备后，切到中间「Catty 对话」，用大白话下达任务，例如：
   "检查所有接口状态，找出 down 的端口并告诉我原因"
   AI 会先用文字说明，再把要执行的命令以卡片列出，
   点「执行」即下发到右侧终端（涉及配置变更的命令会先弹确认框）。
6. 右侧终端实时显示设备输出，可直接敲命令，也能用工具栏做
   批量下发 / 配置比对 / 多设备巡检 / 保存日志。

【界面布局】
   左：设备库 Vault（窄，含搜索/新建/卡片列表）
   中：AI 助手（窄，含 Catty 对话 + AI 高级 两页签）
   右：操作终端（最大）

【安全机制】
· 危险命令（reboot / delete / undo all / factory-reset 等）代码级拦截。
· 任何配置类命令下发前，都会先把完整命令清单展示给你确认，
  确认后才执行；默认不自动保存到设备（save 需手动）。
· 设备密码不写入任何文件，也不打进 exe。
· Telnet 登录失败时立即返回错误（不会反复发送命令当密码重试），
  避免触发设备锁定策略。

【数据存放】
所有配置、日志、资料库默认在用户目录：
   Windows: C:\Users\<你>\.aiterminal\
重新分发时只发 AITerminal.exe 即可，每个使用者有各自独立的配置。
exe 本身可以放在任何位置（包括只读目录如 Program Files），不会向
自身目录写任何文件。

【重新打包（开发者）】
   pip install pyinstaller pillow
   build.bat    （生成 dist\AITerminal.exe）

【快捷键 / 提示】
· 终端区：Ctrl+C 中断，Ctrl+L 清屏，↑↓ 历史命令
· 聊天区：Enter 发送，Shift+Enter 换行
· 批量命令可用工具栏"批量下发"
